# History Content Standard

이 문서는 놀히스토리의 역사 콘텐츠를 작성·검토할 때 사용하는 기준입니다.

## 1. Evidence levels

콘텐츠에서 다음 범주를 구분합니다.

### Fact
신뢰할 수 있는 자료로 확인되는 사실.

### Interpretation
자료를 바탕으로 한 학술적 또는 교육적 해석. 사실처럼 단정하지 않습니다.

### Disputed / uncertain
자료가 부족하거나 연구자·자료 사이 견해가 다른 내용. 불확실성을 표시합니다.

### Tradition / legend
설화, 전승, 후대 기록 등 역사적 사실 여부와 별개로 전해지는 내용.

### Reconstruction / fiction
학습을 위해 구성한 대화, 장면, 선택지 등. 실제 기록과 혼동되지 않게 합니다.

## 2. Source priority

일반적인 우선순위:

1. 당대 1차 사료와 검증된 번역
2. 국가기관·공공 박물관·공식 아카이브
3. 학술 논문·전문 연구서
4. 신뢰할 수 있는 전문 백과·교육 자료
5. 일반 대중용 2차 자료
6. 출처가 불명확한 블로그·커뮤니티·AI 생성문

낮은 단계의 자료만으로 중요한 사실을 확정하지 않습니다.

## 3. What must be checked

본문뿐 아니라 다음도 역사 정보입니다.

- 연도와 날짜
- 인명과 호칭
- 지명과 당시 행정/국가 범위
- 지도 경계
- 복식과 머리 모양
- 건축물
- 무기와 도구
- 음식
- 화폐와 물건
- 교통수단
- 문자와 언어 표현
- 신분·직업·제도
- 당시 존재하지 않았을 가능성이 있는 물건

이미지 생성 프롬프트도 같은 검증 기준을 적용합니다.

## 4. Child-facing adaptation

- 어려운 문장을 짧게 바꿀 수는 있지만 인과관계를 바꾸지 않습니다.
- 현대 가치 판단을 과거 사람의 동기로 자동 대입하지 않습니다.
- 폭력·차별·전쟁 등은 학습 목적에 필요한 만큼 설명하고 선정적으로 묘사하지 않습니다.
- “나쁜 사람/좋은 사람” 식의 단순화보다 행동, 맥락, 결과를 설명합니다.
- 역사적 용어 중 꼭 필요한 개념은 삭제하지 말고 풀어서 설명합니다.

## 5. Dates and chronology

- 서로 다른 달력 체계가 관련될 경우 기준을 명시합니다.
- 정확한 날짜가 불확실하면 임의로 날짜를 만들지 않습니다.
- 연대가 추정일 경우 “약”, “무렵”, “추정” 등의 표현을 사용합니다.
- 연표에서 동시대 사건을 비교할 때 시간 단위가 같은지 확인합니다.

## 6. Conflicting sources

출처가 충돌하면:

1. 어떤 주장들이 있는지 기록한다.
2. 각 주장을 지지하는 자료 수준을 비교한다.
3. 서비스에서 반드시 하나를 고를 필요가 있는지 판단한다.
4. 합의가 없으면 불확실성을 사용자에게 적절한 수준으로 표시한다.

## 7. AI-generated content

AI는 초안·요약·표현 개선·검토 보조에 사용할 수 있지만 **AI 출력 자체는 역사적 근거가 아닙니다.**

게시 가능한 사실 주장으로 사용하기 전에 외부 근거를 확인합니다.

## 8. Content review checklist

- [ ] 사실/해석/전승/창작이 구분되는가
- [ ] 핵심 주장에 근거가 있는가
- [ ] 날짜·인명·지명·물건을 확인했는가
- [ ] 이미지나 시각자료에 시대착오가 없는가
- [ ] 출처가 서로 충돌하는 부분을 숨기지 않았는가
- [ ] 쉬운 표현으로 바꾸며 의미가 왜곡되지 않았는가
- [ ] 현대적 가치판단을 과거 사실처럼 서술하지 않았는가
- [ ] 출처 메타데이터를 추적할 수 있는가
