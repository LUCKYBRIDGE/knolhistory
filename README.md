# 놀히스토리 (knolhistory)

역사 학습 경험을 위한 웹 서비스 프로젝트입니다.

현재 저장소는 **기능 구현 전 설계 단계**입니다. 구체 기능을 서둘러 고정하기보다, 제품 목표·역사 콘텐츠 기준·기술 구조·검증 방법을 먼저 합의하고 구현합니다.

## 작업 원칙

1. 역사적 사실과 해석을 구분합니다.
2. 사실 주장에는 검증 가능한 근거가 있어야 합니다.
3. 학습자에게 보여 주는 콘텐츠와 내부 데이터/출처를 분리합니다.
4. UI보다 정보 구조와 학습 흐름을 먼저 설계합니다.
5. 백엔드·로그인·DB는 실제 요구가 생길 때 도입합니다.
6. 변경 후에는 관련 검증을 수행하고 결과를 남깁니다.

## 프로젝트 문서

- `AGENTS.md` — AI/개발자가 항상 따라야 할 저장소 규칙
- `GOALS.md` — 제품 목표, 성공 조건, 비목표
- `PLANS.md` — 단계별 개발 계획
- `docs/PRODUCT_SPEC.md` — 제품 요구사항과 미결정 사항
- `docs/ARCHITECTURE.md` — 기술 설계 원칙
- `docs/HISTORY_CONTENT_STANDARD.md` — 역사 콘텐츠 작성·검증 기준
- `.agents/skills/` — 반복 작업용 저장소 로컬 스킬

## 현재 단계

**Phase 0 — Foundation**

아직 특정 프레임워크나 데이터베이스를 확정하지 않습니다. 먼저 서비스 핵심 경험과 콘텐츠 단위를 정한 뒤 기술 선택을 진행합니다.
